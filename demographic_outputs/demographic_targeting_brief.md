# Demographic Targeting Brief — For Recommendations Team

Each row is one cluster archetype. Priority tiers reflect reactivation ROI:
- **P1** = high intent + clear demographic profile + actionable channel
- **P2** = large or strategically important, requires more nuanced approach
- **P3** = low signal, cold-start problem, or low recovery probability

All data sourced from `demographic_outputs/` CSVs generated by `demographic_analysis_by_cluster.ipynb`.
