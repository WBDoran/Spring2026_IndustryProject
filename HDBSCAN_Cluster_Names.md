# HDBSCAN Cluster Names

This is a concise naming sheet for the HDBSCAN clusters. The clusters are ordered by their size not cluster number. Each cluster has:

- a `feature proposed name`: simpler stakeholder-facing label
- a `technical proposed name`: slightly more explicit behavioral label

Where relevant, the active-cluster names also reflect the fact that current API depth and API usage are part of what differentiates the stronger active populations overall.
